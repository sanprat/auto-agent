# Gemini and Antigravity Agent Memory Rules

## Before starting any task:
1. Read `.agent-memory-rules.md` in the project root.
2. Read `.agent_memory/current_handoff.md` if it exists.
3. Look for:
   - Similar tasks
   - Previous bugs
   - Architectural decisions
4. Follow all retrieved rules, conventions, and handoff notes.
5. Use retrieved context in reasoning.

## After completing the task:
1. Update memory with learnings.
2. Specifically, update `.agent_memory/current_handoff.md` with details of the task.
3. Store:
   - Task summary
   - Success/failure status
   - Files modified
   - Key decisions
   - Errors encountered (if any)

## Rules:
- MUST update memory after EVERY task.
- MUST read memory before coding.
- Keep entries concise, clear, and reusable.
- If memory write/read fails, retry once, then proceed.
